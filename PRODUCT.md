# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 16 (App Router), React 19, Bun, Tailwind CSS, Mapbox GL JS, Neon PostgreSQL

## Users

Drivers, road trip enthusiasts, and car owners planning scenic drives across the UK, monitoring fuel cost & elevation telemetry, and managing their car garage and recorded drives.

## Product Purpose

Roadr is a map-first route planning and drive telemetry web application. It combines precision UK routing with elevation profiles, road curvature analysis, vehicle-specific fuel estimates, and cloud account sync.

## Positioning

Flighty-inspired map-first telemetry app for driving enthusiasts, delivering live drive telemetry, hairpin/twisties count, elevation profiles, vehicle garage management, and seamless account persistence in a ultra-refined obsidian glassmorphic interface.

## Operating Context

Map-centric navigation workspace with persistent sidebars, live flight-status style telemetry cards, interactive 3D camera preview along route geometries, garage vehicle switcher, and admin control panels.

## Capabilities and Constraints

- Mapbox GL JS interactive 3D map rendering & route polyline layers
- Real-time UK fuel price integration (fuelmap.co.uk)
- Elevation profile sampling & gradient telemetry calculations
- Scoped multi-vehicle garage management & recorded drive logs
- User authentication & session persistence via Neon PostgreSQL cloud database
- Light/Dark theme switching & mobile responsive HUD layout

## Brand Commitments

Visual identity deeply inspired by **Flighty** (apple design award winner flight tracking app):
- Obsidian glassmorphism & liquid glass headers
- Crisp mono badges, neon cyan/teal & amber accents, vibrant telemetry status cards
- Flight HUD inspired route preview controls with bearing/zoom dials and speed multipliers
- High contrast, legible typography and smooth micro-animations

## Product Principles

1. **Map-First Focus**: Interface elements float gracefully over a full-bleed map workspace.
2. **Flighty Telemetry Craft**: Present drive data (distance, fuel, pace notes, hairpins) with airport/flight HUD precision.
3. **Impeccable Visual Finish**: Sleek obsidian dark modes, refined typography, glowing accents, and responsive liquid glass panels.
